# Mint identity pilot 01

This experiment contains unmodified copies of stationary PCnose+ trials used
to build the first mint identity classifier.

Dataset:

- 15 blank trials;
- 15 mint trials;
- 20 bergamot trials;
- 20 lemongrass trials.

All 70 files use the same Cyranose 320 unit, 32 unfiltered sensor channels, and
the same flag-1 reference / flag-3 sample structure. Recording date is retained
as metadata but is not an exclusion rule. Validation groups readings by trial,
not by recording day.

`raw/pcnose/` is organized by class. The originals remain in
`C:\Users\dell-xps\smell-tracing`; these repository copies should not be
rewritten. `trial_manifest.csv` is generated by notebook 05 and records phase
counts, source paths, dates, and QC warnings.

Current audit:

- all 70 files contain 32 sensor channels and 58 flag-3 sample rows;
- six files have one-row phase-count warnings and remain usable;
- no mint trial has a QC warning.

The analysis is intentionally hierarchical:

1. detect blank versus any recorded odor;
2. distinguish mint from bergamot and lemongrass using the relative 32-sensor
   fingerprint;
3. multiply the two model scores and attach them to lag-corrected spatial
   positions.

Stationary trials teach the odor fingerprints. A raster containing every
training odor is not required. Spatial rasters are separate tests of whether
the learned fingerprint transfers while the sensor is moving.

The current claim is mint specificity against the tested bergamot and
lemongrass panel. Additional odor classes can be added under a later pilot
without renaming or invalidating this experiment.

Notebook 05 reports:

- odor-presence grouped trial AUC: 1.000;
- mint-versus-recorded-odors grouped trial AUC: 0.995;
- three-odor held-out-trial accuracy: 92.7%;
- logistic trial AUC: 0.973 versus median tiny-MLP AUC 0.965;
- existing blank-raster median mint score: 0.000;
- existing blotter-mint-raster median mint score: 0.805.

These are pilot results on the tested odor panel. Scores are not independently
calibrated probabilities, and the spatial run remains unsuitable for exact
source-geometry scoring.

Notebook 06 extends the same 70-trial dataset into a three-state causal temporal
model for active mint, mint recovery, and no active mint. The selected bundle
is frozen under `frozen-models/temporal-mint-seeker-v1/`. It contains the
original odor-presence and mint-identity stages, the temporal model, sensor and
feature configuration, model card, data digests, and checksum. New spatial
shapes are independent tests and must not be used to retune this version.

Deployment is hierarchical. Temporal active-mint evidence is mapped only when
the frozen odor-presence model scores at least 0.5; otherwise it is set to zero
before smoothing. Recovery is left ungated because residual recovery can remain
while current odor presence falls. This policy is stored in
`frozen-models/temporal-mint-seeker-v1/deployment_policy.json` and changes no
fitted weights. The gate is applied per reading before spatial smoothing. It
removed all 34 active-state false positives in the known-clean startup lane
(median odor-presence score 0.047; 0/34 passed). The after-temporal heatmap
shows a dashed 0.5 working-detection contour; any faint interpolated color
outside that contour remains below the deployment threshold. Spatial
presentation uses the deployment policy's 2.0-second working pose correction,
chosen as a conservative tested compromise after the fixed-target lag audit;
this does not change the fitted classifier artifact.
