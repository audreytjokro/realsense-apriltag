# Experiments

This folder organizes recordings by their current experimental purpose. The
names are deliberately descriptive and may be extended as the project evolves.
Timestamped session folders retain their original names so raw data remains
traceable to terminal output and metadata.

- `pose-tracking/`: early camera, AprilTag, cube, and snout tracking sessions.
- `exploratory-mapping/`: early odor-map sessions recorded before the structured
  lag protocol.
- `response-lag/`: controlled forward/reverse and blank trials used to estimate
  the Cyranose's physical response delay.
- `classifier/`: stationary PCnose+ odor trials and classifier experiment
  records. The first pilot contains blank, mint, bergamot, and lemongrass.

See `manifest.md` for the current session index.
