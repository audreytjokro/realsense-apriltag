# Cyranose response-lag experiments

The forward/reverse protocol estimates the physical delay between the snout
passing an odor source and the Cyranose sensor response. Opposite scan
directions turn the temporal delay into opposite spatial offsets.

- `lag-tests-valid/` contains the fixed blank control and primary Pairs 2 and 3.
- `lag-tests-excluded/` preserves earlier or path-mismatched attempts.

The current working result is a 3.0 s physical response lag, with Pair 2 and
Pair 3 estimates of 2.90 s and 2.79 s. See the generated report under
`analysis/reports/` for the supporting plots and quality checks.
