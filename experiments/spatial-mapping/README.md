# Spatial mapping experiments

This stage contains recordings where synchronized Cyranose measurements are
mapped into the fixed desk-tag coordinate system.

Subfolders describe the source geometry or scan design. Status folders such as
`pilot-usable/` describe the current analysis decision without implying that a
pilot is a final validated result. Add future geometries alongside the current
line-raster stage rather than renaming older sessions.

The active two-source experiment is
`parallel-strips/mint-lavender-parallel-pilot-01/`. It replaces the earlier
T-shaped design in the main analysis because both reported horizontal sources
are crossed by the raster. The earlier T pilot remains under
`superseded-pilots/` with its original executed notebook and report for
provenance.

`random-waypoint-sequences/` is reserved for longer moving recordings that
avoid a fixed raster order. The independent waypoint guide logs optional
seeded suggestions and recorder-relative timing beside each timestamped
session without controlling the acquisition pipeline.
